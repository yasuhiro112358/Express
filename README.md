# Express

# Create a new project
```bash
# Create a new directory
npm init

# Install express
npm install express
```

# Run the project
```bash
node app.js
```

# Create a skeleton of new project using express-generator
```bash
npx express-generator

# install dependencies:
npm install

# run the app:
DEBUG=express:* npm start
```
